# ✅ Чек-лист Налаштування RAG Chatbot з API

Використовуйте цей чек-лист для перевірки, що всё правильно налаштовано.

## 📋 Этап 1: Підготовка

### Вибір провайдера
- [ ] Вибраний провайдер: **OpenAI** / Anthropic / Cohere
- [ ] Створено кабіне навчання провайдера
- [ ] Отримано API ключ
- [ ] API ключ збережено в безпечному місці (не в гіті!)

### Встановлення
- [ ] Python 3.10+ встановлено
- [ ] Проект клонований/завантажений
- [ ] Знаходжусь у папці `rag-chatbot`
- [ ] Віртуальне середовище активовано (якщо використовується)

## 🔧 Этап 2: Конфігурація

### Залежності
- [ ] Запущено `pip install --upgrade -r requirements.txt`
- [ ] Немає помилок під час встановлення
- [ ] OpenAI пакет встановлено: `pip list | grep openai`

### Переменні середовища
- [ ] Скопійовано `.env.example` в `.env`
- [ ] `.env` знаходиться у корні проекту
- [ ] `.env` **НЕ** коміцений в Git

### Содержимое .env
- [ ] `LLM_PROVIDER` установлено правильно
- [ ] `LLM_API_KEY` вставлено (без пробілів на початку/кінці)
- [ ] `LLM_MODEL_NAME` вірна для вибраного провайдера
- [ ] Файл зберіжено (Ctrl+S)

#### Перевірити .env:
```bash
# Unix/Mac:
cat .env | grep "LLM_"

# Windows PowerShell:
Get-Content .env | Select-String "LLM_"
```

## 🔍 Этап 3: Перевірка конфігурації

### Основні компоненти
- [ ] Файл `app/services/llm_service.py` містить API код
- [ ] Файл `app/config.py` має `llm_provider` і `llm_api_key`
- [ ] Файл `requirements.txt` має `openai==1.3.0`

### Vector Store
- [ ] Папка `vector_store/` існує або буде створена
- [ ] Папка `vector_store/` не коміцена в Git

### Старі файли видалені
- [ ] Папка `models_cache/` видалена або ігнорується
- [ ] Немає файлів Llama 2 лишків

## 🚀 Этап 4: Запуск

### Тестування запуску
```bash
# Запустіть сервер
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

- [ ] Сервер запустився без помилок
- [ ] Мова: `OpenAI client initialized successfully!` (або ваш провайдер)
- [ ] Адреса http://localhost:8000 доступна
- [ ] Swagger UI працює на http://localhost:8000/docs

### Перевірки здоров'я
```bash
# Перевірити здоров'я
curl http://localhost:8000/health
```

- [ ] Відповідь: `{"status": "ok"}`

```bash
# Перевірити конфіг
curl http://localhost:8000/api/config
```

- [ ] Відповідь містить: `"llm_provider": "openai"`
- [ ] Відповідь **НЕ** містить вашого API ключа

## 📝 Этап 5: Функціональність

### Базова функціональність
- [ ] Swagger доступний
- [ ] Можна розглянути ендпойнти
- [ ] Можна розглянути схеми даних

### Завантаження документа (опціонально)
```bash
# Створіть тестовий файл
echo "Це тестовий PDF вміст" > test.txt

# Завантажте його через API або в Swagger UI
```

- [ ] Мога завантажити файл без помилок
- [ ] Файл обробився правильно
- [ ] Папка `vector_store/` має вміст

### Чат (опціонально)
```bash
# Запит через cURL
curl -X POST "http://localhost:8000/api/rag/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "Привіт!",
    "session_id": "test",
    "top_k": 3
  }'
```

- [ ] Отримано 200 відповідь (або 400 якщо БД пуста)
- [ ] Відповідь JSON валідна
- [ ] **Немає помилки про API ключ**

## 🔍 Этап 6: Перевірка помилок

### Якщо сервер не запустився:

```bash
# Перевірьте Python
python --version  # Мають бути 3.10+

# Перевірьте залежності
pip list | grep openai

# Перевірьте .env
cat .env

# Запустіть з деталями помилки
python -m uvicorn app.main:app --reload 2>&1
```

- [ ] Всі залежності встановлені
- [ ] Python версія правильна
- [ ] Немає синтаксичних помилок

### Якщо проблем з API:

```bash
# Перевірьте API ключ
echo $LLM_API_KEY  # Unix/Mac
echo $env:LLM_API_KEY  # Windows PowerShell

# Тестуйте API ключ напрямо
curl -H "Authorization: Bearer YOUR_KEY" \
  https://api.openai.com/v1/models \
  -H "User-Agent: Mozilla/5.0"
```

- [ ] API ключ встановлено в оточенні
- [ ] API ключ починається з `sk-proj-` (OpenAI)
- [ ] API ключ не має пробілів/символів переносу
- [ ] У вас є залишок кредиту на API

### Якщо вектор-БД не працює:

```bash
# Видаліть старий вектор-store
rm -rf vector_store/

# Перезапустіть
python -m uvicorn app.main:app --reload
```

- [ ] Папка `vector_store/` пересоздана
- [ ] Нема помилок про Chroma
