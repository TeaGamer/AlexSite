## 🚀 Швидкий Старт (5 хвилин)

### 1️⃣ Отримайте API ключ
```
OpenAI: https://platform.openai.com/api-keys
Anthropic: https://console.anthropic.com/
Cohere: https://dashboard.cohere.com/
```

### 2️⃣ Налаштуйте .env
```bash
cp .env.example .env

# Відредагуйте .env:
LLM_PROVIDER=openai
LLM_API_KEY=sk-proj-your-actual-key
LLM_MODEL_NAME=gpt-3.5-turbo
```

### 3️⃣ Встановіть залежності
```bash
pip install --upgrade -r requirements.txt
```

### 4️⃣ Запустіть
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 5️⃣ Тестуйте
```
Swagger: http://localhost:8000/docs
```

## 🎓 Що намісто освітлювати?

**Система RAG (Retrieval Augmented Generation)**

1. **Документи** → завантажуються
2. **Embeddings** → створюються локально (DistilBERT)
3. **Vector Store** → зберігаються в Chroma
4. **Запит** → користувач пітає
5. **Пошук** → семантичне пошук в vector store
6. **Контекст** → найкращі результати
7. **LLM** → OpenAI генерує відповідь з контекстом
8. **Відповідь** → повертається користувачу
